00:00:38:21 — how a project moves

Five passes,
start to delivery.

The same signal path on every project, so nothing slips between raw footage and final export.

INGEST

Footage & brief intake

Raw files, brand guidelines, and reference cuts land in one shared bin — organized and logged before anyone touches a timeline.

ASSEMBLY

Rough cut

A first pass in the right order and the right length, so you're approving structure before we polish anything.

FINE CUT

Pacing & story pass

Trims, transitions, motion graphics, and text — the edit starts to feel like the finished piece.

COLOR + MIX

Grade & audio mix

Color correction, grading, sound design, and a level mix so it plays the same on a phone speaker as a monitor.

DELIVER

Export & handoff

Every aspect ratio and file spec you need, plus the project file — nothing locked to us alone.
